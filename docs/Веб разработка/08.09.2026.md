# Платформа .NET, язык C# и ASP.NET Core

*   **.NET** — кроссплатформенная платформа разработки от Microsoft. Она предоставляет:
    *   Среду выполнения программ (Runtime).
    *   Библиотеки классов (готовые решения для типовых задач).
    *   Инструменты разработки.
    *   Систему управления пакетами (NuGet) и сборки проектов.
*   **C#** — основной объектно-ориентированный язык программирования, работающий на платформе .NET.
*   **ASP.NET Core** — современный кроссплатформенный фреймворк с открытым исходным кодом для создания веб-приложений, API и облачных сервисов.

**Как связаны Browser, ASP.NET Core и C#?**
1. Браузер отправляет HTTP-запрос.
2. ASP.NET Core принимает запрос и организует его обработку.
3. C# выполняет серверную бизнес-логику (работу с данными, расчеты).
4. ASP.NET Core формирует HTTP-ответ.
5. Браузер получает ответ и отображает результат пользовuтелю.

### Ключевые компоненты платформы
*   **SDK (Software Development Kit)** — набор инструментов для *создания* приложений (компиляторы, отладчики, утилиты командной строки).
*   **Runtime** — среда, необходимая только для *запуска* уже готовых скомпилированных приложений.
*   **CLR (Common Language Runtime)** — «виртуальная машина» .NET, которая управляет выполнением кода: собирает мусор (освобождает память), обрабатывает исключения и обеспечивает безопасность типов.
*   **IL (Intermediate Language)** — промежуточный язык, в который компилируется код C#. Позже CLR превращает этот IL-код в машинный код конкретной операционной системы (этот процесс называется JIT-компиляцией).

### Основы C# и ООП
*   **Переменная** — именованная область памяти для хранения значения. Имя объясняет, *что* хранится, а тип определяет, *какие* значения допустимы.
*   **Тип данных** — правило, определяющее размер выделяемой памяти и набор операций, которые можно выполнять с переменной (например, `int`, `string`, `bool`).
*   **Decimal** — тип данных для хранения денежных значений. Он предназначен для десятичных чисел с высокой точностью, поэтому он **исключает ошибки округления**, характерные для типов с плавающей точкой (`float`, `double`), что критически важно для финансовых расчетов.
*   **Класс** — чертеж или шаблон, описывающий структуру (данные) и поведение (действия) будущих объектов.
*   **Объект** — конкретный экземпляр класса, созданный по этому шаблону.
*   **Свойство** — характеристика объекта, описывающая его состояние (например, `Color`, `Price`, `Name`).
*   **Метод** — функция, которая является частью класса и описывает действие, которое объект может совершать (например, `CalculateTotal()`, `Save()`).

### Веб-сервер и архитектура ASP.NET Core
*   **Kestrel** — кроссплатформенный веб-сервер по умолчанию в ASP.NET Core. Он непосредственно «слушает» сеть, принимает сырые HTTP-запросы и передаёт их дальше в приложение.
    > *Заметка: Kestrel принимает запросы, а ASP.NET Core (через middleware) их обрабатывает.*
*   **Program.cs** — в современных проектах это основная точка входа, конфигурации и запуска приложения. Здесь происходит:
    *   Регистрация сервисов (Dependency Injection).
    *   Создание экземпляра приложения (`WebApplication.CreateBuilder`).
    *   Подключение middleware (промежуточного ПО).
    *   Настройка маршрутизации (Routing).
    *   Запуск приложения (`app.Run()`).
*   **Middleware** — компонент конвейера (pipeline) обработки HTTP-запросов. Он получает контекст запроса, выполняет свою узкую задачу (например, проверяет авторизацию или логирует данные) и передает управление следующему компоненту. *Простыми словами: это цепочка функций-фильтров, через которые проходит каждый запрос.*
*   **UseRouting()** — метод, включающий механизм маршрутизации. Он сопоставляет входящий URL-адрес с подходящим обработчиком (endpoint) в коде.

### Протокол HTTP

**Запрос HTTP состоит из:**
*   **Method** — действие, которое клиент хочет выполнить (намерение).
*   **URL** — адрес конкретного ресурса на сервере.
*   **Headers (Заголовки)** — метаданные запроса (например, язык, тип браузера, токены авторизации, формат принимаемых данных).
*   **Body (Тело)** — полезные данные, передаваемые на сервер (например, JSON с данными новой статьи). Есть не у всех запросов (у GET тела обычно нет).

**Основные HTTP-методы (глаголы):**
*   **GET** — получение данных с сервера (безопасный метод, не меняет состояние сервера).
*   **POST** — создание нового ресурса на сервере.
*   **PUT** — *полное* обновление существующего ресурса (заменяет его целиком).
*   **PATCH** — *частичное* обновление ресурса (меняет только указанные поля).
*   **DELETE** — удаление ресурса.

**Дополнительные понятия HTTP:**
*   **Content-Type** — заголовок, указывающий формат данных в теле запроса или ответа (например, `application/json` или `text/html`).
*   **HTTP-ответ** — реакция сервера на запрос, содержащая код состояния, заголовки и (часто) тело с данными.
*   **Status-codes (Коды состояния):**
    *   **2xx (Успех):** Запрос успешно обработан (например, `200 OK`, `201 Created`).
    *   **4xx (Ошибка клиента):** Клиент отправил некорректный запрос (например, `400 Bad Request`, `401 Unauthorized`, `404 Not Found`).
    *   **5xx (Ошибка сервера):** Сервер не смог выполнить корректный запрос из-за своей внутренней ошибки (например, `500 Internal Server Error`, `503 Service Unavailable`).
*   **HTTPS** — защищенная версия HTTP, где все передаваемые данные шифруются с помощью протокола TLS/SSL, что предотвращает их перехват и подмену злоумышленниками.
