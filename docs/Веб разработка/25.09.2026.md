## ЧАСТЬ 1: HTML (Чистая структура)

### База и метаданные
`<!DOCTYPE html>` - указывает браузеру на стандарт HTML5.
`<html lang="ru">` - корневой элемент, язык страницы.
`<head>` - невидимые метаданные (кодировка, заголовок, стили).
`<meta charset="UTF-8">` - кодировка (всегда первая строка в head).
`<meta name="viewport" content="width=device-width, initial-scale=1.0">` - адаптивность под мобильные устройства.
`<title>` - текст на вкладке браузера.
`<link rel="stylesheet" href="style.css">` - подключение внешнего CSS.
`<body>` - всё видимое содержимое страницы.

### Текст и форматирование
`<h1>` ... `<h6>` - заголовки (h1 только один на страницу).
`<p>` - параграф текста.
`<strong>` - важный текст (жирный).
`<em>` - акцентированный текст (курсив).
`<br>` - принудительный перенос строки (одиночный).
`<hr>` - тематическая разделительная линия (одиночный).
`<blockquote>` - блочная цитата.
`<code>` - фрагмент кода.
`<pre>` - текст с сохранением всех пробелов и переносов.

### Ссылки и медиа
`<a href="url" target="_blank">` - гиперссылка (`_blank` открывает в новой вкладке).
`<img src="путь" alt="описание">` - картинка (одиночный, `alt` обязателен).
`<video src="..." controls>` - видеоплеер.
`<audio src="..." controls>` - аудиоплеер.
`<source>` - альтернативный источник для video/audio.
`<iframe src="...">` - встроенная внешняя страница (YouTube, карты).

### Списки
`<ul>` - маркированный список (точки).
`<ol>` - нумерованный список (цифры).
`<li>` - элемент списка (вкладывается только в ul или ol).

### Таблицы
`<table>` - контейнер таблицы.
`<thead>`, `<tbody>`, `<tfoot>` - смысловые группы строк.
`<tr>` - строка таблицы.
`<th>` - ячейка-заголовок (жирная).
`<td>` - обычная ячейка с данными.

### Формы
`<form action="url" method="POST">` - обёртка формы.
`<label for="id_инпута">` - текстовая подпись (связывается с инпутом через id).
`<input>` - поле ввода. Типы: `text`, `password`, `email`, `checkbox`, `radio`, `file`, `submit`.
`<textarea>` - многострочное текстовое поле.
`<select>` - выпадающий список.
`<option>` - пункт выпадающего списка.
`<button type="submit">` - кнопка отправки.

### Группировка и семантика
`<div>` - блочный контейнер без смысла (для сетки и стилей).
`<span>` - строчный контейнер без смысла (для стилизации части текста).
`<header>` - шапка сайта или секции.
`<footer>` - подвал сайта или секции.
`<main>` - основное уникальное содержимое (один на страницу).
`<nav>` - блок навигации (меню).
`<section>` - тематический раздел контента.
`<article>` - самостоятельный контент (статья, карточка товара).
`<aside>` - побочный контент (сайдбар, реклама).
`<figure>` и `<figcaption>` - иллюстрация и подпись к ней.

## ЧАСТЬ 2: CSS (Селекторы и магия выбора)
*Основано на механике CSS Diner. Синтаксис: `селектор { свойство: значение; }`*

### 1. Базовые селекторы
* **По тегу:** `plate` — выбирает все элементы с именем тега `plate`.
* **По классу (`.`):** `.small` — выбирает все элементы, у которых есть атрибут `class="small"`.
* **Тег + класс:** `orange.small` — выбирает только теги `orange`, у которых есть класс `small` (без пробела!).
* **По ID (`#`):** `#fancy` — выбирает единственный элемент с `id="fancy"`. ID должен быть уникален на странице.
* **Универсальный (`*`):** `*` — выбирает абсолютно все элементы на странице.

### 2. Комбинаторы (Связи между элементами)
* **Потомки (пробел):** `plate apple` — выбирает все `apple`, которые находятся внутри `plate` на *любом* уровне вложенности.
* **Прямые дети (`>`):** `plate > apple` — выбирает только те `apple`, которые являются *непосредственными* детьми `plate` (без промежуточных тегов).
* **Соседний элемент (`+`):** `plate + apple` — выбирает `apple`, который стоит *сразу же* после `plate` на том же уровне вложенности.
* **Общие соседи (`~`):** `bento ~ pickle` — выбирает все `pickle`, которые следуют за `bento` и имеют с ним одного родителя.
* **Группировка (`,`):** `plate, bento` — выбирает и `plate`, и `bento` (объединение условий).
* **Все внутри:** `plate *` — выбирает все элементы-потомки (любого типа) внутри `plate`.

### 3. Псевдоклассы (Состояния и позиция)
* **`:first-child`** — `orange:first-child` выбирает `orange`, только если он самый первый дочерний элемент своего родителя.
* **`:last-child`** — `.small:last-child` выбирает элемент с классом `small`, если он самый последний у своего родителя.
* **`:only-child`** — `plate > :only-child` выбирает элемент, если он *единственный* ребенок у своего родителя (который является `plate`).
* **`:nth-child(N)`** — `:nth-child(3)` выбирает 3-й по счету элемент среди всех детей родителя (независимо от тега).
* **`:nth-last-child(N)`** — `bento:nth-last-child(3)` считает с конца и выбирает 3-й элемент `bento` с конца.
* **`:first-of-type`** — `apple:first-of-type` выбирает первый элемент `apple` среди всех `apple` у одного родителя.
* **`:last-of-type`** — `orange:last-of-type, apple:last-of-type` выбирает последний `orange` и последний `apple` своего типа.
* **`:nth-of-type(формула)`** — `plate:nth-of-type(even)` выбирает `plate` на четных позициях (2, 4, 6). `plate:nth-of-type(2n+3)` выбирает каждый второй элемент, начиная с 3-го (3, 5, 7...).
* **`:only-of-type`** — `plate apple:only-of-type` выбирает `apple`, если он единственный тег `apple` у своего родителя (другие теги могут быть).
* **`:empty`** — `bento:empty` выбирает элементы `bento`, внутри которых нет вообще ничего (ни текста, ни других тегов, ни пробелов).
* **`:not(селектор)`** — `apple:not(.small)` выбирает все `apple`, у которых НЕТ класса `small`.

### 4. Селекторы атрибутов (`[ ]`)
* **Наличие атрибута:** `[for]` — выбирает любой элемент, у которого есть атрибут `for` (значение не важно).
* **Тег + атрибут:** `plate[for]` — выбирает только `plate`, у которых есть атрибут `for`.
* **Точное значение:** `[for="Vitaly"]` — выбирает элементы, где атрибут `for` в точности равен `"Vitaly"`.
* **Начинается с (`^=`):** `[for^="Sa"]` — значение атрибута `for` начинается с `"Sa"`.
* **Заканчивается на (`$=`):** `[for$="ato"]` — значение атрибута `for` оканчивается на `"ato"`.
* **Содержит подстроку (`*=`):** `[for*="obb"]` — значение атрибута `for` содержит `"obb"` в любом месте.

## ЧАСТЬ 3: CSS (Свойства и макет)

### Блочная модель (Box Model)
Каждый элемент — это коробка. Порядок снаружи внутрь: `margin` -> `border` -> `padding` -> `content`.
* `width` / `height` - размеры контента.
* `padding` - внутренний отступ (до границы).
* `border` - граница (например, `1px solid black`).
* `margin` - внешний отступ (до других элементов).
* **Правило:** Всегда добавляй в начало CSS: `* { box-sizing: border-box; }`, чтобы padding и border не увеличивали заданную ширину элемента.

### Единицы измерения
* `px` - пиксели (жесткие).
* `%` - процент от размера родителя.
* `vw` / `vh` - процент от ширины/высоты окна браузера.
* `rem` - относительно размера шрифта корня (`<html>`). Идеально для отступов и шрифтов.

### Display (Отображение)
* `block` - занимает всю ширину, начинается с новой строки (`div`, `p`, `h1`).
* `inline` - занимает только размер контента, не переносится, игнорирует width/height (`span`, `a`, `strong`).
* `inline-block` - как строчный, но можно задавать width/height.
* `none` - элемент полностью исчезает из потока (не занимает место).

### Position (Позиционирование)
* `static` - по умолчанию, обычный поток.
* `relative` - сдвиг относительно своего обычного места (через `top`, `left` и т.д.).
* `absolute` - вырывается из потока. Позиционируется относительно ближайшего родителя с `position` (не static).
* `fixed` - вырывается из потока. Привязан к окну браузера (не двигается при скролле).
* `sticky` - "прилипает" к краю экрана при скролле, пока не кончится родитель.
* `z-index` - порядок наложения по оси Z (кто выше). Работает только с position (кроме static).

### Flexbox (Выравнивание в одну ось)
Родитель: `display: flex;`
* `flex-direction: row | column` - главная ось (горизонталь или вертикаль).
* `justify-content` - выравнивание по главной оси (`flex-start`, `center`, `space-between`, `space-around`).
* `align-items` - выравнивание по поперечной оси (`stretch`, `center`, `flex-start`).
* `flex-wrap: wrap` - разрешает перенос элементов на новую строку.
* `gap: 20px` - отступы между элементами.
Дочерние: `flex-grow: 1` (растягивать), `flex-shrink: 0` (не сжимать).

### Grid (Двумерные сетки)
Родитель: `display: grid;`
* `grid-template-columns: 1fr 2fr 1fr` - ширина колонок (fr = свободная доля).
* `grid-template-rows: 100px auto` - высота строк.
* `gap: 20px` - отступы между ячейками.
Дочерние: `grid-column: 1 / 3` - элемент растягивается с 1-й по 3-ю вертикальную линию.

### Текст и цвета
* `color: #ff0000` (или `red`, `rgb()`, `rgba()` с прозрачностью).
* `font-size: 16px;` - размер шрифта.
* `font-family: 'Arial', sans-serif;` - шрифт с запасным вариантом.
* `font-weight: 400 | 700 | bold;` - жирность.
* `text-align: center;` - выравнивание текста.
* `text-decoration: none;` - убирает подчеркивание ссылок.
* `line-height: 1.5;` - межстрочный интервал (без единиц измерения).

### Фон и границы
* `background-color: #fff;`
* `background-image: url('img.jpg');`
* `background-size: cover;` - картинка заполняет весь блок, обрезаясь по краям.
* `background-position: center;` - центрирование фона.
* `border-radius: 10px;` - скругление углов (50% делает круг).
* `box-shadow: 0 4px 6px rgba(0,0,0,0.1);` - тень (сдвиг-X, сдвиг-Y, размытие, цвет).

### Адаптивность (Media Queries)
Пишется в самом конце CSS файла.
```css
/* Стили для экранов шириной ДО 768px (планшеты и телефоны) */
@media (max-width: 768px) {
    .container { flex-direction: column; }
}
```

### Полезные фишки
* `cursor: pointer;` - курсор-рука при наведении.
* `transition: all 0.3s ease;` - плавная анимация изменений (писать на исходном состоянии).
* `transform: scale(1.1) rotate(45deg);` - трансформация без сдвига соседних элементов.
* `opacity: 0.5;` - прозрачность всего элемента (от 0 до 1).
* `overflow: hidden;` - обрезает всё, что вылезает за границы блока.
* `white-space: nowrap;` - запрет переноса текста на новую строку.
* `text-overflow: ellipsis;` - ставит многоточие (...) если текст не влезает (требует `white-space: nowrap` и `overflow: hidden`).
