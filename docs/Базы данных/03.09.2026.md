# Основные понятия баз данных

**Данные** - это факты, представленные в форме, пригодной для обработки компьютером (цифры, текст, даты и т.д.). Сами по себе данные могут не иметь смысла.

**Информация** - это данные, которые получили смысл в определённом контексте. Например, число "25" - это данные, а "температура воздуха 25 градусов" - уже информация.

**Информационная система** - это совокупность средств, методов и процессов, предназначенных для сбора, хранения, обработки и выдачи информации. Простыми словами - это система, которая помогает работать с данными и превращать их в полезную информацию.

**Сущность** - это объект реального мира или предметной области, о котором мы хотим хранить информацию. Например: студент, товар, заказ, книга.

**Экземпляр сущности** - это конкретный представитель сущности. Если "студент" - это сущность, то "Иванов Иван Иванович, группа ИТ-21" - это экземпляр этой сущности.

**Атрибут сущности** - это характеристика или свойство сущности. Для сущности "студент" атрибутами будут: фамилия, имя, номер группы, дата рождения.

**Идентификатор сущности** - это уникальный признак, который позволяет отличить один экземпляр сущности от другого. Например, номер студенческого билета или ИНН для человека. Каждый экземпляр должен иметь уникальный идентификатор.

**Связь между сущностями** - это логическое отношение, которое показывает, как экземпляры одной сущности связаны с экземплярами другой сущности.

### Пример структуры базы данных

| Сущность      | Атрибуты                                                                                          |
| :------------ | :------------------------------------------------------------------------------------------------ |
| Студент       | Номер студенческого билета, Номер группы, Имя, Фамилия, Отчество, Адрес проживания, Дата рождения |
| Преподаватель | ID преподавателя, Имя, Фамилия, Отчество, Дата рождения, ID должности                             |
| Группа        | Название, ID специальности                                                                        |
| Оценка        | Балл, ID студента, ID предмета, ID преподавателя, Дата выдачи                                     |
| Дисциплина    | ID дисциплины, Кол-во часов, Название дисциплины                                                  |
| Специализация | ID специализации, Название специализации                                                          |
| Должность     | ID должности, Название должности                                                                  |
| Специальность | ID специальности, Название специальности                                                          |
**Ключевой атрибут** - это атрибут (или набор атрибутов), который уникально идентифицирует каждый экземпляр сущности.
