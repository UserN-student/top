# Основные атрибуты ConstraintLayout

**ConstraintLayout** — современный контейнер для создания сложных интерфейсов с помощью относительного позиционирования элементов. Вместо вложенных контейнеров используются ограничения (constraints), которые привязывают элементы друг к другу или к родительскому контейнеру.

## Основные атрибуты привязки

| Атрибут                                  | Описание                                                                            |
| ---------------------------------------- | ----------------------------------------------------------------------------------- |
| `layout_constraintTop_toTopOf`           | Верх элемента привязывается к верху другого элемента                                |
| `layout_constraintTop_toBottomOf`        | Верх элемента привязывается к низу другого элемента                                 |
| `layout_constraintBottom_toTopOf`        | Низ элемента привязывается к верху другого элемента                                 |
| `layout_constraintBottom_toBottomOf`     | Низ элемента привязывается к низу другого элемента                                  |
| `layout_constraintStart_toStartOf`       | Начало элемента (слева в LTR) привязывается к началу другого элемента               |
| `layout_constraintStart_toEndOf`         | Начало элемента привязывается к концу другого элемента                              |
| `layout_constraintEnd_toStartOf`         | Конец элемента привязывается к началу другого элемента                              |
| `layout_constraintEnd_toEndOf`           | Конец элемента привязывается к концу другого элемента                               |
| `layout_constraintBaseline_toBaselineOf` | Базовая линия текста одного элемента привязывается к базовой линии другого элемента |

## Пример использования

```xml
<TextView
    android:id="@+id/textView1"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Привет"
    app:layout_constraintTop_toTopOf="parent"
    app:layout_constraintStart_toStartOf="parent" />

<TextView
    android:id="@+id/textView2"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Мир"
    app:layout_constraintTop_toBottomOf="@id/textView1"
    app:layout_constraintStart_toStartOf="parent" />
```

В примере первый текст привязан к верху и началу родительского контейнера, а второй текст размещается под первым элементом
# Единицы измерения в Android

При разработке интерфейсов в Android используются различные единицы измерения для обеспечения корректного отображения элементов на устройствах с разной плотностью экрана и размерами.

## Основные единицы измерения

| Единица | Название | Для чего используется |
|---------|----------|----------------------|
| **px** | Пиксели | Почти никогда. Не рекомендуется использовать, так как пиксели не масштабируются под плотность экрана |
| **dp (dip)** | Density-independent pixels | Размеры, отступы, ширина, высота элементов интерфейса. Основная единица измерения |
| **sp** | Scale-independent pixels | Только для размеров шрифтов. Масштабируется вместе с настройками доступности пользователя |
| **pt** | Points | Для шрифтов в печати (1/72 дюйма). Редко используется в Android |
| **mm** | Миллиметры | Физический размер элемента |
| **in** | Дюймы | Физический размер элемента |

## Разница между dp и sp

**dp (density-independent pixels)** — используются для всех размеров элементов интерфейса (кнопок, отступов, размеров view). Эти единицы не зависят от плотности экрана и обеспечивают одинаковый визуальный размер на разных устройствах.

**sp (scale-independent pixels)** — используются **только** для размеров текста. Помимо независимости от плотности экрана, sp также масштабируются в соответствии с настройками размера шрифта в системе Android (настройки доступности).

## Пример использования в XML

```xml
<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Пример текста"
    android:textSize="16sp"
    android:padding="16dp"
    android:layout_margin="8dp" />

<Button
    android:layout_width="200dp"
    android:layout_height="48dp"
    android:text="Нажми меня"
    android:textSize="14sp" />
```

## Почему не стоит использовать px

Использование пикселей (px) приводит к тому, что элементы интерфейса будут иметь разный физический размер на экранах с разной плотностью. На устройстве с высокой плотностью экрана элементы будут слишком маленькими, а на устройстве с низкой плотностью — слишком большими.

## Формула преобразования

Приблизительное соотношение:
- 1 dp = 1 px на экране с плотностью 160 dpi (mdpi)
- 1 dp = 2 px на экране с плотностью 320 dpi (xhdpi)
- 1 dp = 3 px на экране с плотностью 480 dpi (xxhdpi)

## Рекомендации

- Всегда используйте **dp** для размеров элементов и отступов
- Всегда используйте **sp** для размеров текста
- Избегайте использования **px** в разметке
- Физические единицы (mm, in, pt) используйте только для специфических задач, связанных с печатью или точными физическими размерами
